Deployment Order

Resources are deployed in this dependency order.

1

PKI / Bootstrap

cert-manager (optional) → SelfSigned Issuer → Root CA → CA Issuer

cert-manager 1.19.3 SelfSigned Issuer Root CA · 90d CA Issuer
2

Secrets & Config

5 TLS leaf Secrets + 5 credential Secrets + 4 ConfigMaps

node-tls · admin-tls · dashboard-tls · filebeat-tls · api-tls indexer-cred · dashboard-cred · api-cred · authd-pass · cluster-key
3

Storage / PVCs

PVCs via StatefulSet volumeClaimTemplates (ReadWriteOnce)

indexer-PVC × 3 master-PVC × 1 worker-PVC × 2 snapshots-PVC (opt, RWX)
4

Workloads

StatefulSets, Deployment, DaemonSet, post-install Job

Indexer StatefulSet × 3 securityadmin Job ruleset-reload Job Manager Master × 1 Manager Workers × 2 Dashboard × 1 Agent DaemonSet
5

Networking

Services, optional Ingress / Gateway API, NetworkPolicies, PodDisruptionBudgets

indexer · indexer-nodes · master · cluster · worker · dashboard manager-lb (opt, LB) Ingress / Gateway API (opt)
6

CI / CD

Chart release pipeline — entirely separate from the cluster

release.yaml (GH Actions) chart-releaser-action v1.7.0 gh-pages → Artifact Hub
